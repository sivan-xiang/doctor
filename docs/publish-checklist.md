# 发布检查清单（publish-checklist）

每次发布前逐项确认，全部勾选后方可合并主分支触发自动构建部署。

- [ ] frontmatter 校验通过（`npm run validate` 退出码 0）
- [ ] 目标内容 `status` 为 `published`
- [ ] 审核表已归档到 `/docs/reviews/`，且内容版本与审核表一致
- [ ] 无违规表述（确诊 / 治愈 / 替代就医 / 保证有效 等）
- [ ] 急救内容包含 `when_to_seek_help`
- [ ] 免责声明存在（首页、详情页、关于页）
- [ ] 首页 / 搜索结果预览正常
- [ ] 120 拨号入口可点击，含手动拨打兜底提示
- [ ] 移动端与微信内置浏览器兼容性抽查
- [ ] Git 提交信息注明「内容 + 审核表」

```
# 内容审核表

- 审核人：

- 合规意见：
- 是否通过：
- 备注：
```
